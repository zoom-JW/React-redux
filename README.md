# React + Redux Shopping Cart

Цей проект є прикладом інтеграції Redux у React-додаток за допомогою Redux Toolkit. Він реалізує простий каталог товарів з можливістю додавання їх до кошика.

## Виконані вимоги

Проект було відрефакторено згідно з вимогами:

1.  **Аналіз існуючого стану:**
    *   Визначено частини додатку, що потребують асинхронних операцій — завантаження даних з API у `CardList.tsx`.
    *   Глобальним станом визначено список товарів у кошику (`items`). Цей стан необхідний для відображення кількості та загальної вартості у `Store.tsx`, а також для взаємодії з кнопками у `Button.tsx`.

2.  **Рефакторинг з використанням асинхронних дій (Redux Thunk):**
    *   Використано `createAsyncThunk` для створення асинхронної дії `fetchProducts`, яка отримує дані з `https://fakestoreapi.com/products`.
    *   Оновлено `shopSlice`, додавши обробку станів `pending` (завантаження), `fulfilled` (успіх) та `rejected` (помилка).
    *   Підключено асинхронні дії до компонентів, використовуючи `useDispatch` для запиту та `useSelector` для відображення стану.

3.  **Створення компонентів:**
    *   У директорії `src/components` створено файли компонентів: `Header.tsx`, `Footer.tsx`, `Card.tsx`, `CardList.tsx`, `Store.tsx`, `Button.tsx`.
    *   Використано Tailwind CSS v3.4 для стилювання компонентів — адаптивність та функціональність збережено.
    *   Забезпечено адаптивність: навігація у `Header.tsx` прихована на мобільних пристроях (`hidden md:flex`).

4.  **Використання компонентів:**
    *   Всі компоненти імпортовано та використовуються у `App.tsx`.
    *   `Header` та `Footer` обрамлюють основний контент сторінки.
    *   `Store` отримує дані кошика через `useSelector`.
    *   `CardList` передає об'єкти товарів (`CardItem`) у `Card` через props.
    *   `Button` отримує `item: CardItem` через props і диспетчеризує дії `addItem` / `clearItems`.

5.  **Тестування проекту:**
    *   Перевірено, що всі асинхронні операції (`fetchProducts`) працюють коректно — дані завантажуються з API.
    *   Перевірено коректне оновлення UI при змінах стану через асинхронні дії: відображається індикатор завантаження (`loading`), дані (`succeeded`) або помилка (`failed`).
    *   Перевірено функціонал кошика: додавання товарів, очищення, підрахунок суми.

## Запуск проекту

Для запуску проекту локально виконайте наступні команди:

```bash
# Встановлення залежностей
npm install

# Запуск сервера розробки
npm run dev
```
